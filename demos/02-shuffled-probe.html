A control task shows what a probe can score by memorising

In Hewitt and Liang's control task, each word type is given a fixed random tag, so the only way to score well is to memorise; the same linear probe still reaches 71.2%, against 97.2% on part of speech.

Both bars come from the same linear probe on the same activations of ELMo's first layer; only the labels change. The control task gives each word type a fixed random tag, so its 71.2% is what the probe scores by memorising alone, and the 26.0-point difference, which Hewitt and Liang call the selectivity, is the number to report. For gender, the corresponding control gives each first name a random label and keeps it fixed across biographies.
