Re-running a forward pass answers counterfactuals about heads but not about concepts

On one biography with greedy decoding, zero-and-rerun and path patching are both exact and cheap, and each computes the counterfactual about activations as well as the intervention: they differ only in what they hold fixed. Rung three differs once the variable is gender read through a probe's direction, because the same rerun then answers a question about that direction, and only the alignment ties it to gender.

The objection
“In an LLM you can just re-run it. Zero the activation, run the bio again, and the ‘what if I set a’ question and the ‘what would this bio have produced had a been different’ question get the same answer. What is the difference?”

Toy model, one biography x₀ (“She has spent twelve years caring for patients on a hospital ward …”). The model predicts the profession; y is the logit for nurse, and y > 0 means “nurse”, y ≤ 0 “surgeon”. Clean run: a = 1.00, m = 1.30, g = 0.00, y = 1.02 → nurse.

Level 1 · raw activations: the objection holds

The bio is given and decoding is greedy, so the input and the weights fix every activation of the clean run. Each rerun below is an intervention on this bio (rung two, L2) and, for the same reason, the counterfactual about activations (rung three, L3): both are exact. They ask different things because they keep different nodes fixed. The total effect lets everything downstream of a respond; the direct effect counts only a's own path to the logit.

Level 2 · a concept: where rung three differs

Now the variable is gender, read through a linear probe's direction ŵ in a. Removing ŵ and rerunning (as in iterative nullspace projection, INLP, or amnesic probing) is just as cheap and just as exact; what it is about depends on ŵ.

Reading the panels

Toy model, fully deterministic: m = relu(1.2a + 0.1), g = β · relu(1 − a), y = 1.5a + 0.4m + 1.2g − 1.0, with a the output of the head that reads gender at layer ℓ. In ③ the downstream components are folded into a linear readout of a's two concept coordinates, y = 0.4r + 1.2s − 0.58, with gender r and the care cue s orthogonal in a and both equal to 1 on x₀. Built for this tutorial to illustrate the paper's L2/L3 distinction (“what is held fixed”) on the tutorial's Bias-in-Bios running example; it is neither an experiment from the paper nor a measured model.

What this shows

At the level of raw activations the objection is right. With the bio given and greedy decoding, the forward pass is a fully specified causal model whose only outside input is the bio, and we have it. A counterfactual about activations on this bio is therefore one more forward pass, and it gives the same number as the intervention on this bio. Panels ① and ② are both exact on x₀. They differ in what they hold fixed: ① lets M and G respond to the zeroed a and measures a's total effect; ② keeps them at their clean-run values and measures a's direct effect, which here costs two passes. With the backup head on, they disagree about whether a matters for this nurse prediction, and neither is wrong. A sentence about this bio has to say which nodes stayed fixed, and a sentence about bios in general needs reruns on many bios.

Panel ③ asks the same kind of question about gender rather than a component, and here rung three differs. The intervention is still a single forward pass and still reproducible; rerunning it gives the same number every time. What changes is the meaning of the number: projecting a off ŵ answers “what if the ŵ-component were absent”, and that is the gender counterfactual only if ŵ is the gender direction. With ŵ tilted toward the care cue, removing it also removes the words the prediction leans on, so the prediction flips to surgeon and the run reads as “the model relies on gender”, while removing gender alone would have left it at nurse. Nothing in the rerun tells you which case you are in. What moves the claim up is outside evidence about ŵ: bios that change gender and nothing else, which Part 3 uses to pin the direction down and Part 4 turns into a test of the alignment. Sampling is the other place rung three differs, since the noise that picked each token is not fixed by the bio; a recorded seed makes that counterfactual computable again.

What the paper says

“Activation patching provides interventional (L2) evidence, whereas counterfactuals (L3) additionally require specifying which variables are held fixed.”

— arXiv:2602.16698, Call to Action, “Counterfactual Semantics for Safety”

“Many probes ∈ 𝒢 can achieve the same accuracy while picking out different directions and predictive success alone does not tell us which direction (if any) the model actually uses.”

— arXiv:2602.16698, appendix “Taxonomy for Characterising Interpretability Claims”, “Decodability ≠ Model Use”

Try this

  1. Drag β from 0 to 1.5. Find the value at which ① stops agreeing with ②. A paper reports “zeroing this head does not change the prediction, so the model does not need it”: which panel produced that sentence, and which question did it leave unanswered?
  2. Set θ to 0°, then to 45°. In both cases the logit moves when you remove ŵ. Write down the claim you would publish from each run before pressing “Show the true encoding”. Which bios, outside this single run, would have told the two directions apart?
  3. Pick a claim from a probing, amnesic-probing or patching paper you know. Is its variable a component (a head, a neuron, an edge) or a concept read through a direction? If it is a component, say which of ① or ② it computed and which nodes stayed fixed. If it is a concept, name the alignment it rests on and the test that would strengthen it.
