Subspace ≠ Coordinates

A symmetry: a change that leaves the loss unchanged.

Each dot is one picture of the ball, placed by the encoder in the two-dimensional activation h; the true axes read the ball’s position and its colour. Turning the learned axes by θ changes every ball’s coordinates on them, while a linear head that turns back by θ returns the same position and colour, so the loss (the squared error of that output) stays at zero. That is a symmetry, a change that leaves the loss unchanged, and nothing in the activations alone picks the true axes over the rotated ones.

Try this: set θ to 63°, the deck’s angle, and read the pink ball’s coordinate on learned axis 1: does it track position, colour, or both?
